# PRYSM Snapshot V1

Status: frozen for the 2026-09-27 staging candidate.

PRYSM Snapshot is a single client-facing lead-magnet page. It proves that
PRYSM reviewed the named business, presents the governed conversion-readiness
signal, shows up to three supported opportunities, gives one evidence-backed
next action, and bridges to the seven-page PRYSM Executive Audit. It is not a
replacement for the Executive Audit.

## Locked rules

- The page is one print page and is written in plain, direct language.
- Scores, findings, counts, competitor claims, and site signals come only
  from persisted governed evidence. Missing data stays unavailable, partial,
  unknown, failed, or not connected.
- The page never shows a price, sample count, internal identifier, model,
  prompt, fixture name, provenance implementation detail, or staging note.
- Findings are capped at three and may be fewer when evidence does not support
  three. The competitor block is omitted unless direct competitor evidence is
  available.
- The header contains PRYSM, `Snapshot · Conversion Readiness`, the audited
  business, canonical domain, supported market, and review date.
- The brand is always spelled `Omnipressence`. The human CTA uses only an
  explicitly configured URL and approved identity; it never infers a booking
  URL or headshot.
- A client logo renders only when the Brand Identity and Asset Gate marks it
  verified. Otherwise the business name is the fallback.

## Page order

Header; Conversion Readiness Summary; Quick Site Signals; Top Conversion
Opportunities; optional Competitive Signal; One Fix You Can Use Now; What Is
Already Helping; Omnipressence Human CTA; locked PRYSM Executive Audit bridge;
What PRYSM Checked sidebar.

## Brand production spine

Audited website -> existing collection and page extraction -> verified,
provenance-bearing brand asset contract -> persisted canonical site evidence ->
Snapshot projection -> Snapshot renderer -> one-page client report.

Raw crawl/provider evidence remains stored for auditability but is not fetched
or searched during rendering.
